# Импорт своих разговоров

Лучший вариант из возможных: кабинет на настоящих разговорах вашего отдела. Синтетика показывает механику, реальные данные показывают ваш бизнес.

## Что подойдёт

Всё, где видно диалог:

- расшифровки звонков из телефонии или из сервиса речевой аналитики
- транскрипты встреч из Zoom, Meet, Teams, SurfNote и подобных
- переписка из WhatsApp или Telegram — экспорт чата текстом
- письма, если продажа идёт почтой
- даже конспекты разговоров, которые менеджер писал сам: хуже, чем запись, но лучше, чем ничего

**Сколько нужно.** Двадцати разговоров достаточно, чтобы увидеть первые закономерности. Ста — чтобы им доверять. Трёхсот — чтобы считать сегментные разрезы.

## Как положить

Сложите файлы в `data/import/` — в любом виде, хоть txt, хоть docx, хоть выгрузку из CRM. Дальше скажите агенту:

```
импортируй мои разговоры
```

Он разберёт файлы, приведёт к формату `data/own/dataset.json` и спросит только то, чего не хватает: кто из говорящих менеджер, к какому этапу воронки отнести разговор, чем закончилось.

## Формат, если хотите сделать руками

```json
{
  "id": "c001",
  "date": "2026-09-01T10:12:00",
  "manager_id": "m2",
  "lead_id": "l003",
  "stage": "discovery",
  "direction": "outbound",
  "duration_min": 14,
  "outcome": "краткий итог одной строкой",
  "transcript": [
    { "who": "manager", "text": "…" },
    { "who": "client",  "text": "…" }
  ]
}
```

Переписка — то же самое, только `messages` вместо `transcript`, и у каждого сообщения есть `ts`.

Полная схема — в [architecture.md](architecture.md).

## Смешанный вариант

Если реальных разговоров мало — импортируйте их и догенерируйте остальное:

```bash
python3 scripts/generate_participant.py active/profile.json --calls 200
```

Синтетика возьмёт стиль и возражения из вашего профиля. В кабинете такие данные помечены отдельно, чтобы вы не перепутали свои выводы с иллюстрацией.

## О чём предупредить команду

Разговоры сотрудников — чувствительные данные. Прежде чем загружать записи, убедитесь, что у вас есть на это право: предупреждение о записи в начале звонка, согласие сотрудников, политика хранения. Кабинет работает локально и ничего никуда не отправляет, кроме вызовов модели — но ответственность за сами данные остаётся на вас.
