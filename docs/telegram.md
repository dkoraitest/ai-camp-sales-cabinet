# Telegram: канал до менеджера

Кабинет открывает руководитель. Менеджер его не открывает — он живёт в мессенджере. Поэтому разбор разговора и задание на отработку уходят туда, где человек их прочитает, через пару минут после звонка, а не на планёрке в пятницу.

Для этого нужен ваш бот. Он создаётся за две минуты, код писать не нужно.

## 1. Создайте бота

1. Откройте в Telegram **@BotFather** и напишите `/newbot`
2. Придумайте имя — его увидят менеджеры, например «Тренер отдела продаж»
3. Придумайте username — он должен заканчиваться на `bot`, например `acme_sales_coach_bot`
4. BotFather пришлёт токен вида `1234567890:AA…` — это пароль от бота

## 2. Вставьте токен

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен в строку `TELEGRAM_BOT_TOKEN=`. Файл `.env` закрыт в `.gitignore` и в репозиторий не попадает. **Токен в чат с агентом не присылайте** — впишите его в файл сами.

## 3. Кабинет узнаёт бота

```bash
python3 scripts/telegram.py init
```

Ответ: «Бот @… на связи». Обновите страницу кабинета — в карточках менеджеров появятся ссылки подключения.

## 4. Подключите менеджеров

Ссылка лежит в двух местах:
- **Руководитель → Команда → «Разбор и сообщения»**: блок «Канал до менеджера» у каждого человека;
- **Менеджер → Мой тренер**: блок «Мой Telegram» — менеджер подключается сам.

Ссылка выглядит как `t.me/ваш_бот?start=m2`: в ней id менеджера. Отправьте каждому его ссылку. Он открывает её и жмёт «Старт». Бот в этот момент молчит — это нормально, постоянно работающего сервера нет, «Старт» только регистрирует чат.

Когда люди нажали «Старт», соберите привязки:

```bash
python3 scripts/telegram.py link --auto
```

Каждому придёт «Готово. Сюда будет приходить обратная связь по разговорам». Привязки лежат в `active/telegram.json`, кабинет видит только имя бота и кто подключён — `cabinet/telegram.js`, без токена и id чатов.

Если ссылки под рукой нет, можно привязать по хендлу: `python3 scripts/telegram.py who` покажет всех, кто писал боту, а `python3 scripts/telegram.py link m2 --user @denis` свяжет вручную.

## 5. Отправьте

```bash
python3 scripts/telegram.py send m2 --dry    # посмотреть текст, ничего не отправляя
python3 scripts/telegram.py send m2          # отправить одному
python3 scripts/telegram.py send all         # всем подключённым
```

Тексты берутся из `cabinet/coach.js` — их пишет шаг 2.

## Что уходит человеку

Два сообщения, оба короткие:

- **После значимого разговора** — что сделано хорошо, с цитатой из его же разговора; что упущено; что сделать конкретно в следующий раз
- **Тренировка** — ситуация из реальных возражений вашей базы и просьба ответить кружком на минуту

## Дальше: доставка сама собой

Сейчас отправка запускается руками. Следующий шаг — по расписанию: разбор считается ночью и уходит утром, тренировка — в понедельник. Это `cron` на любой машине, которая включена утром:

```
0 8 * * 1-5  cd /путь/к/репозиторию && python3 scripts/telegram.py send all
```

Отвечать на кружки и разбирать ответы бот пока не умеет — это следующий уровень тренера.

## Безопасность

Утёкший токен означает, что писать вашим людям от имени компании сможет кто угодно. Если токен где-то засветился — напишите BotFather `/revoke`, получите новый и замените строку в `.env`. Привязки менеджеров при этом сохранятся.
