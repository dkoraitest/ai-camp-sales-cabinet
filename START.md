# Начните отсюда

Откройте эту папку в Claude Code (или в другом код-агенте) и скажите:

```
поехали
```

Дальше агент всё объяснит сам. Кабинета пока нет — он появится на первом шаге, когда у вас будут данные.

---

**Что будет происходить**

| Шаг | Что вы скажете | Что получите |
|---|---|---|
| 0 | `поехали` | Агент расспросит про вашу компанию и соберёт базу разговоров: импортирует ваши записи или сгенерирует под ваш бизнес |
| 1 | `разбери коммуникации` | Появится кабинет с тремя вкладками и первыми инсайтами по вашей команде |
| 2 | `подключи тренера` | Добавится вкладка с картой навыков, обратной связью и тренировками |
| 3 | `обогати лидов` | Добавится вкладка с карточками клиентов и готовыми сообщениями |
| 4 | `глубокая аналитика` | Добавится разбор: что общего у сделок, которые вы выигрываете |

Каждый шаг — несколько минут. Кабинет растёт у вас на глазах.

**Если что-то пошло не так** — скажите агенту `включи демо`. В кабинет ляжет готовый результат текущего шага, и вы продолжите вместе со всеми, а со своими данными разберётесь дома. Посмотреть весь кабинет целиком — `покажи демо`.

**Обновили репозиторий** (`git pull`) — пересоберите кабинет, вкладки останутся те же:

```
python3 scripts/build_cabinet.py --rebuild
```

**После конференции** — скажите `наставник`. Он вспомнит, на чём вы остановились, и подскажет следующий шаг.
