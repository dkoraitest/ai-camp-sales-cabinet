# Заметки только для Claude Code

Основные правила — в `AGENTS.md`: его подключает первая строка этого файла, и его же сам читает Codex. Здесь только то, что касается Claude Code.

## Архитектура: исходники и сборка

- Исходники кабинета — `blocks/`: `_core.html` (каркас, `DataSource`, роли, общие функции, стили) и по файлу на вкладку: `me.js`, `overview.js`, `contacts.js`, `insights.js`, `managers.js`, `leads.js`, `deep.js`.
- `cabinet/index.html` — результат сборки, руками его не правишь. Меняешь `blocks/` и пересобираешь: `python3 scripts/build_cabinet.py --rebuild` для кабинета участника, `--blocks … --out demo` для демо. Кабинет участника и демо не смешиваешь: демо собирается только в `demo/`.
- Инструкции шагов — скиллы в `.claude/skills/`. Папки `iterations/` в репозитории больше нет.

## Вопросы участнику

`AskUserQuestion`: до четырёх вопросов за вызов, у каждого 2-4 варианта, заголовок до 12 символов, вариант «Другое» добавляется сам. Рекомендуемый вариант — первым, с пометкой «(рекомендую)».

## Скиллы

Скиллы шагов подхватываются сами по фразам участника. `.claude/skills/` — источник: если правишь скилл, запусти `python3 scripts/sync_skills.py`, чтобы копия для Codex в `.agents/skills/` не разошлась. Проверка — `python3 scripts/sync_skills.py --check`.
