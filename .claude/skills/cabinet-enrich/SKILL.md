# Шаг 3 · Обогащение и коммуникация

Кабинет умеет оценивать разговоры и учить команду. Последний шаг — помочь менеджеру подготовиться к разговору, который ещё не состоялся.

**Главная мысль шага:** исход разговора решается до звонка — тем, что вы успели узнать о человеке.

## Что делаешь

1. Возьми 5–8 лидов на фокусном этапе из конфига (не всех — на воркшопе нет времени)
2. Для каждого собери контекст и подготовь сообщение
3. Запиши в `cabinet/enrich.js`

## Откуда берётся контекст

**В демо-режиме** внешних источников нет — работаешь с тем, что в датасете: индустрия, размер, источник лида, история звонков по этому лиду, что клиент говорил дословно. Этого достаточно, чтобы показать механику.

**В реальной работе** сюда подключаются веб-поиск по компании, новости, профили ЛПР, госреестры. Если у участника есть интернет и он хочет попробовать на своей реальной компании — сделай полноценный поиск, это сильнее любого демо.

Скажи участнику прямо: в демо контекст берётся из его же данных, но архитектура кабинета не изменится, когда он подключит внешние источники. Меняется только наполнение карточки.

## Как писать сообщение

Одно сообщение на лида, 4–6 предложений. Структура:

1. **Зацепка из его реальности** — факт о компании или ситуации, не о нас. Если факт из прошлого разговора — сошлись на него дословно
2. **Связь с проблемой** — что из этого факта следует для его бизнеса
3. **Что мы с этим делаем** — одна фраза, без списка возможностей
4. **Следующий шаг** — конкретный, с вариантом времени

**Чего не делает сообщение:**
- не начинается с «Меня зовут… Наша компания является…»
- не перечисляет функции продукта
- не содержит слов «уникальный», «инновационный», «индивидуальный подход»
- не просит «уделить пару минут» без причины

Проверка: если это сообщение можно отправить любой другой компании, заменив название — оно не готово.

## Формат файла

Создай `cabinet/enrich.js`:

```js
window.CABINET_ENRICH = {
  leads: [
    {
      id: "l07",
      context: "Логистика, 95 человек, пришёл с сайта. На демо 02.09 спросил про приёмку товара без штрихкодов — значит поставщики работают вразнобой. Следующий шаг после демо не зафиксирован, с тех пор 10 дней тишины.",
      message: "Тимур, добрый день. Вы спрашивали, что делать с поставщиками, которые везут товар без штрихкодов — у дистрибьюторов это чаще всего самая дорогая часть приёмки.\n\nМы посчитали на похожем складе: маркировка на входе один раз закрывает вопрос на всех следующих этапах, приёмка ускоряется примерно вдвое.\n\nГотов показать на ваших номенклатурах, 20 минут. Вторник до обеда или среда после трёх?"
    }
  ]
};
```

В `message` переносы строк — `\n\n`, кабинет отрисует их как абзацы.

## Что сказать участнику

«Открой вкладку Лиды — обогащённые карточки помечены, внутри контекст и готовое сообщение». Здесь же уместно сказать, что enrichment и скоринг не отдельные инструменты, а две функции одной карточки клиента.
