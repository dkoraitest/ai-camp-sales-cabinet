# Подключи CRM

Кабинет — рабочий слой поверх CRM. Сегодня он читает файлы из `data/`, дальше — сделки из CRM участника.

**На воркшопе этот шаг не делается:** нужны ключи доступа, настройка интеграции и время. Если участник просит в зале — покажи `connectors/README.md`, скажи, что это первое дело после конференции, и вернись к шагам.

## Что делаешь после конференции

1. Прочитай `connectors/README.md` — контракт: какие поля кабинету нужны от любой CRM
2. Спроси, какая CRM (ответ шага 0 лежит в `active/profile.json`, поле `crm`). Для amoCRM и Битрикс24 есть маппинг полей: `connectors/amocrm.md`, `connectors/bitrix24.md`
3. Попроси участника создать доступ по инструкции из файла маппинга и положить ключ в `.env`. **Ключ в чат не принимай и в код не вписывай**
4. Напиши `scripts/connectors/<crm>.py`: API → `data/own/dataset.json` по контракту. Начни с чтения: сделки, этапы, ответственные, менеджеры. Разговоры и запись обратно — вторым заходом
5. Сопоставь этапы CRM с воронкой из `cabinet/config.js` вместе с участником: покажи таблицу соответствий и спроси «так?»
6. Запусти коннектор, потом `python3 scripts/build_data.py` и `python3 scripts/build_cabinet.py --rebuild`
7. Плашка в шапке кабинета покажет источник данных

## Чего не делать

- Не ходить в CRM из браузера: никакого `fetch` из `index.html`, ключи не попадают в страницу
- Не писать сразу запись обратно: сначала участник должен увидеть свои сделки в кабинете и убедиться, что этапы сопоставлены правильно
