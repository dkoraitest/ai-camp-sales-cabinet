# Демо-кабинет

Открывает `demo/index.html` — собранный кабинет со всеми вкладками на демо-базе: 271 коммуникация компании DataFlow Solutions, две роли, разбор по матрице, тренер, следующее касание и глубокая аналитика.

**Если у участника сломался конкретный шаг** — лучше `включи демо` (skill `demo-step`): эталон этого шага ляжет в его кабинет, и он продолжит со всеми по шагам.

## Когда использовать

**У участника что-то сломалось и время уходит.** Не чините на ходу — откройте демо и продолжайте вместе со всеми. Со своими данными человек разберётся дома, инструкция у него останется.

**Участник хочет увидеть, к чему идём.** Иногда полезно показать результат до того, как его собирать.

**Спикер показывает со сцены.** Здесь ничего не генерируется и не может упасть.

## Как открыть

```bash
open demo/index.html          # macOS
start demo\index.html         # Windows
xdg-open demo/index.html      # Linux
```

## Что сказать участнику

Спокойно и без извинений: «Открой demo — там собранный кабинет на демо-данных. Дальше идём по шагам, а со своей базой разберёмся после конференции, у тебя всё для этого есть».

Выпасть из потока хуже, чем не починить ошибку прямо сейчас.

## Чем демо отличается от того, что собирает участник

Ничем, кроме данных. Тот же каркас, те же вкладки, те же заготовки из `blocks/`. Разница в том, что демо собрано заранее и лежит в репозитории готовым, а кабинет участника растёт по шагам на его собственной базе.
