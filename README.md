# Кабинет продаж

Рабочий прототип аналитической платформы для отдела продаж. Собирается за одно выступление, открывается в браузере, передаётся руководителю одной папкой.

> Воркшоп сессии **«AI в продажах и коммуникациях»** — AI Camp Almaty, 21 сентября 2026.
> Спикер: Дмитрий Коробовцев, AI Surfers.

---

## Что вы соберёте

CRM, у которой фундамент — не карточки, а коммуникации. Она читает звонки **и переписку**, раскладывает их по вашей воронке и отвечает на вопросы, на которые сегодня никто не отвечает:

- где в воронке теряются сделки и почему
- кто из команды в чём силён, а где проседает
- какие возражения повторяются чаще всего
- что лучшие менеджеры делают иначе

Сверху надстраиваются три вещи: персональная обратная связь менеджеру сразу после значимого контакта, тренировочные кейсы под его слабые навыки и подготовка следующего касания с клиентом.

### Матрица оценки

Система работает в два слоя. Сначала **извлекает факты**: этап воронки, карту участников, SPSV (сегмент, ситуация, проблема, решение, ценность словами клиента), квалификацию, возражения дословно, договорённости, сигналы, конкурентов. Потом **оценивает работу** по семи показателям: структура разговора, глубина выявления, качество квалификации, работа с ценой и возражениями, управление сделкой, экспертность, баланс диалога.

Эти же семь показателей становятся картой навыков менеджера — и под провалившийся показатель система подбирает тренировку.

## Как запустить

**Что нужно:** Claude Code (или любой код-агент), Python 3 для пересборки данных. Ничего больше — ни сборки, ни сервера, ни установки зависимостей.

```bash
git clone <repo>
cd ai-camp-sales-cabinet
```

Откройте `cabinet/index.html` двойным кликом — увидите кабинет на демо-данных. Дальше четыре шага, каждый запускается одной фразой в код-агенте:

| Шаг | Команда | Что появится |
|---|---|---|
| **0** | `настрой кабинет` | Ваша воронка, матрица оценки и **база разговоров вашей компании** |
| **1** | `разбери коммуникации` | Разбор каждого звонка и переписки + инсайты по команде |
| **2** | `подключи тренера` | Карта навыков, обратная связь, тренировки, отправка в Telegram |
| **3** | `обогати лидов` | Контекст по клиенту и готовое сообщение |
| **4** | `глубокая аналитика` | Что общего у выигранных сделок, SPSV по сегментам, карта возражений |

После каждого шага обновите страницу в браузере — появится новый блок.

### Откуда берутся данные

На шаге 0 агент спросит, есть ли у вас записи разговоров или переписки.

- **Есть** — сложите файлы в `data/import/`, он разберёт их сам. Подойдут расшифровки звонков, транскрипты встреч, экспорт чата из WhatsApp. Подробнее — [docs/import.md](docs/import.md)
- **Есть немного** — импортируем их и дополняем до рабочего объёма
- **Нет** — агент соберёт профиль вашей компании и сгенерирует около 350 диалогов под вашу индустрию, воронку и возражения. Занимает секунды: смысл делает модель, объём делает скрипт

Демо-база в `data/b2b` и `data/b2c` остаётся как запасной вариант и как пример формата.

## Что внутри

```
cabinet/           кабинет: открывается двойным кликом, без сборки
  index.html       интерфейс
  data.js          данные (собираются из data/)
  config.js        воронка, матрица, вопросы — заполняет шаг 0
  scores.js        разбор коммуникаций — после шага 1
  coach.js         карта навыков и тренировки — после шага 2
  enrich.js        обогащение — после шага 3
  deep.js          кросс-аналитика — после шага 4
reference/         эталон: как выглядит собранный кабинет целиком
data/
  b2b/             демо-данные: длинный цикл, несколько ЛПР
  b2c/             демо-данные: поток заявок, быстрое решение
scripts/
  build_data.py    пересобрать data.js после правки датасетов
docs/
  architecture.md  как подключить свою CRM вместо демо-данных
```

Два профиля данных нужны потому, что B2B с циклом в три месяца и B2C с потоком заявок спрашивают у своих разговоров разное. Профиль выбирается на шаге 0. В каждом профиле есть и звонки, и переписка — они склеиваются по сделке и этапу воронки.

## Дальше, после конференции

Скажите агенту `наставник` или `что дальше` — он посмотрит, на каком шаге вы остановились, и подскажет ближайшее действие. Главное следующее действие обычно одно: заменить демо-данные на свои двадцать разговоров. Этого достаточно, чтобы увидеть первые реальные закономерности.

Подключение CRM, телефонии и регулярных выгрузок — в [docs/architecture.md](docs/architecture.md).
Переделать кабинет в полноценное приложение на компонентной библиотеке — [docs/upgrade-ui.md](docs/upgrade-ui.md).

## Ограничения, о которых честно

Это прототип, а не продукт. Он не записывает звонки, не расшифровывает речь, не разделяет голоса, не ходит в вашу CRM сам и не звонит менеджеру голосом, чтобы потренировать — для этого нужна инфраструктура, которую за два часа не собрать. Кабинет работает с текстами разговоров и переписок, которые вы ему дали.

Сообщения в Telegram он не только готовит, но и отправляет: на воркшопе — через общего бота, дома — через вашего. Как это включить, описано в [docs/telegram.md](docs/telegram.md).

Всё остальное в нём — настоящее: критерии ваши, оценки по вашим правилам, выводы по вашим данным.
